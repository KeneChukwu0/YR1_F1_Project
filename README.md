This project seeks to provide a lightweight method to view both current and historic Formula 1 results. Using the FastF1 API, the program can display a season's timetable, a simple set of session results or an advanced set of session results.
The GUI is implemented using NiceGUI which provides the backend to create a browser based GUI. The CLI is implemented with the default Python functionality. 

I developed this project in order to better understand the use of APIs and how to implement them in practise as, at the point of writing this, I have had little experience with them in a practical sense through my formal CS education.
